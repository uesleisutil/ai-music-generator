### 🚀 Próximos Passos

1. **Instalar Dependências:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Configurar YouTube API:**
   - Seguir instruções em `SETUP.md`
   - Obter `client_secrets.json`

3. **Testar o Sistema:**
   ```bash
   python test_setup.py
   ```

4. **Gerar Primeira Música:**
   ```bash
   python pipeline.py --prompt "cozy lofi music" --duration 30 --title "Test"
   ```
