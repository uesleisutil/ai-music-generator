## 🚀 Como Usar

### Teste Rápido (Sem IA)
```bash
python aimusic simple --prompt "lofi music" --duration 30 --skip-upload
```

### Qualidade Profissional (Com IA)
```bash
# 1. Instalar modelos
pip install -r requirements-full.txt

# 2. Gerar
python aimusic ai --prompt "cozy lofi coffee shop" --duration 60 --skip-upload
```
